# Juegodelasnake
# Juego de la Serpiente (Snake Game)

Implementación del clásico juego de la serpiente desarrollado en Python utilizando **Pygame** para la interfaz gráfica y el bucle de juego.

## Características

- Interfaz gráfica fluida y responsiva.
- Sistema de puntuación en tiempo real.
- Controles intuitivos mediante el teclado.
- Detección precisa de colisiones (paredes y propio cuerpo).

## Requisitos previos

Asegúrate de tener instalado Python en tu computadora. Necesitarás instalar la librería `pygame`.

Ejecuta el siguiente comando en tu terminal para instalar la dependencia:

```bash
pip install pygame
```

## Cómo ejecutar el proyecto

1. Clona este repositorio o descarga los archivos en tu computadora.
2. Entra a la carpeta del proyecto en tu terminal.
3. Ejecuta el archivo principal:

```bash
python Juego_de_la_snake.py
```
